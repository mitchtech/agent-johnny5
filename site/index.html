Agent Johnny 5 plays lines from Short Circuit when Claude Code, Codex, or Gemini CLI needs you: an approval waiting, a question asked, a turn finished. And it yells "No disassemble!" when that approval is for rm -rf. The robot himself is a Codex pet that installs on its own.

Destructive-command alarm

No disassemble.

When an approval is for something you cannot take back, the cue changes. Recursive force deletes, force pushes, hard resets, dropped tables, mkfs, dd, and their PowerShell cousins all get the alarm instead of the ordinary prompt.

It is a louder cue, not a safety check. The hook never blocks, approves, logs, or stores the command; only a yes/no flag leaves it.

approval
agent wants to run:
$ rm -rf ./build ./dist
allow? [y/n]

Codex pet

Number five, on screen.

Johnny 5 is also a native Codex pet: nine animations, sixteen look directions, binocular optics, expressive brow shutters, and tank treads. Codex drives the animation from what your agent is doing. Here, you drive it.

The pet installs on its own. It never enables sounds, and the sound plugin never installs or selects a pet.

Download pet ZIP ↓Pet guide ↗
  1. Extract the johnny5 folder into ~/.codex/pets/, or the pets folder inside your configured CODEX_HOME. No Node.js needed.
  2. Refresh the desktop pet picker and choose Johnny 5, or enter /pets Johnny 5 in a supported Codex CLI terminal.
Prefer the command line?
npm install -g github:mitchtech/agent-johnny5#v__VERSION__
agent-johnny5 pet install
agent-johnny5 doctor --pet

These commands install pet files only and never change your selected pet. agent-johnny5 pet uninstall removes an unchanged CLI-managed installation.

Install

Two commands. Johnny 5 is alive.

Run these in your terminal. Node.js 22+ and a local audio player are required. Restart your agent after installation.

Claude Code

claude plugin marketplace add mitchtech/agent-johnny5
claude plugin install johnny5@agent-johnny5

Codex

codex plugin marketplace add mitchtech/agent-johnny5
codex plugin add johnny5@agent-johnny5

Gemini CLI

gemini extensions install https://github.com/mitchtech/agent-johnny5

Review and trust the sound hooks in Codex's hook settings. Running Agent Navi, Agent Warcraft, or Agent StarCraft too? Enable one per host so a fairy, a robot, a peon, and an SCV do not talk over each other. Other agents use the standalone event interface.

Sound controls
agent-johnny5 status
agent-johnny5 mute prompt_submitted
agent-johnny5 mute easter-egg
agent-johnny5 preset attention
agent-johnny5 unmute all

Or ask your agent to "mute Johnny 5" through the bundled control skill. Global mute preserves your event preferences.
